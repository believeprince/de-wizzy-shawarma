# De Wizzy Shawarma

Premium food ordering and event-booking website for De Wizzy Shawarma, Port Harcourt.

## Features

- Responsive React/Vite storefront
- Menu categories and search
- Cart and WhatsApp ordering
- Event/catering booking form
- De Wizzy branding and menu pricing
- Professional stock food photography
- Pickup and delivery messaging

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

> Food photos are presentation stock images and should be replaced with De Wizzy's own product photography when available.
